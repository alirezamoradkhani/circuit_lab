# پلن بازی پازل داستانی «مدار گمشده»

محل: `docs/game-plan/`

این پوشه، طراحی بخش بازی مستقل پروژه است. هیچ‌کدام از قابلیت‌های شرح‌داده‌شده در این اسناد به معنی پیاده‌سازی‌شدن آن‌ها نیست. بخش آموزشی و هشت مأموریت فعلی حفظ می‌شوند؛ این کمپین، تعریف تجربهٔ تازهٔ بازی است، نه تغییر نام مراحل قبلی.

## قرارداد تجربه
بازیکن باید بتواند با حرکت، کشف، کشیدن کابل، جابه‌جایی باتری، تغییر رفتار دستگاه‌ها و دیدن پیامد کارش سرگرم شود. هدف‌ها از جنس «خودت را به پشت‌بام برسان» و «دوستت را از مخزن بیرون بیاور» هستند. فرمول و مولتی‌متر ابزار اختیاری فهم مسئله‌اند؛ پاسخ عددی، شرط عبور از داستان نیست.

مبنای تصویری پیشنهادی: محیط و شخصیت سه‌بعدی، حرکت روی سطح، دوربین ثابت مایل؛ همان رویکرد ۲٫۵بعدی گفت‌وگو. نام‌ها، تعداد مراحل و جزئیات داستان در این سند پیشنهاد طراحی‌اند و قابل اصلاح‌اند.

## دامنهٔ پیشنهادی نسخهٔ کامل
- یک کمپین ۱۲مرحله‌ای با سه فصل و ارتباط داستانی پیوسته.
- حدود ۲٫۵ تا ۳٫۵ ساعت برای اولین تجربه، صرفاً برآورد طراحی و نیازمند تست بازیکن.
- سه فضای محله‌ای؛ هر مرحله چند قاب متصل دارد، نه یک جهان باز بزرگ و خالی.
- رازها، واکنش‌های طنز و مسیرهای جایگزین برای بازپخش؛ زمان‌سنج اجباری و جان محدود نداریم.
- موفقیت با تغییر وضعیت جهان ثبت می‌شود؛ تابلو نتیجه می‌تواند خلاصه‌ای کوچک باشد.
- اسناد، طراحی بازی‌اند؛ انتخاب موتور، کتابخانه، دارایی‌ها و کدنویسی در این درخواست انجام نمی‌شود.

## قالب فایل هر مرحله
وعدهٔ سرگرمی، هدف، نقشهٔ محیط، اشیا و قوانین، روند ورود، معمای اصلی، راه‌حل‌ها، سرنخ‌ها و دیالوگ، شکست و بازگشت، راز، دوربین و کنترل، دارایی‌های لازم و معیار پذیرش. مسیر پیشنهادی طراح در فایل‌ها آمده تا حل‌پذیری قابل بررسی باشد؛ این متن نباید داخل بازی به کاربر نمایش داده شود.
