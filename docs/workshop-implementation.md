# اجرای مرحلهٔ اول «مدار گمشده»

از منوی بالای سایت «داستان رِی» یا نشانی `/#workshop` وارد شوید. فعلاً فقط تعمیرگاه قابل بازی است؛ مراحل ۲ تا ۱۲ در پوشهٔ پلن هستند. آزمایشگاه و «شهر روشن» مسیرهای مستقل قبلی باقی مانده‌اند.

## آنچه اجرا شده
- اتاق سه‌بعدی با دوربین مایل، مدل‌های رِی و پاک‌رو، سایه، بافت سطوح و نور موضعی چراغ؛ رنگ‌ها با مرجع هنری انتخاب‌شده تنظیم شده‌اند.
- مقدمهٔ کوتاه قابل ردکردن، حرکت با مسیریابی و برخورد با موانع، انتخاب مستقیم اجسام، چرخ‌دستی متحرک و درِ کرکره‌ای.
- دو راه حل: باتری رِی یا قرقرهٔ کابل و پریز ثابت. برد نیازمند ضامن باز، رسید برداشته‌شده و عبور واقعی از آستانه است.
- انرژی ۷۲ ژولی، مصرف ۳ وات چراغ/رادیو و پالس ۶ژولی ضامن؛ شارژ مجدد از پریز، محدودیت طول کابل و قطع صریح اتصال.
- ولت‌متر فقط خواندنی، نمای مدار با توقف زمان، کیف و رسید، سرنخ مرحله‌ای، راز چراغ و رادیو و صدای ساخته‌شده با Web Audio.
- ذخیرهٔ مستقل وضعیت با کلید `circuit-lab.story.workshop.v1`؛ بازچینی وسایل و شروع تازه دو عمل جدا هستند.
- روی نمایش عمودی، دوربین با زاویهٔ ثابت همراه ربات جابه‌جا می‌شود. دکمهٔ نمای کامل، همهٔ اتاق را نشان می‌دهد.

## کنترل‌ها
| کار | روش |
|---|---|
| حرکت | کلیک/لمس زمین، WASD، کلیدهای جهت یا دستهٔ لمسی |
| تعامل | کلیک روی جسم، E یا دکمهٔ دست |
| کابل | C یا ابزار کابل؛ انتخاب دو سوکت در هر ترتیب |
| جداکردن | تکرار همان اتصال یا انتخاب سوکت متصل و «جدا کردن کابل» |
| اندازه‌گیری | M یا ولت‌متر؛ سپس سوکت |
| کیف | Tab وقتی صحنه فوکوس دارد، یا دکمهٔ کیف |
| سرنخ | H یا دفتر راهنما |
| بررسی مدار | نماد چشم در نوار ابزار؛ جهان هم‌زمان متوقف می‌شود |
| بازگشت | Escape |
| بازچینی | R یا نماد بازنشانی؛ انتخاب بازچینی یا شروع تازه |

## ساختار
- `src/campaign/workshop/`: قواعد مستقل از مرورگر، دادهٔ چیدمان، برق و ارتباط کنش‌ها با مدل.
- `src/campaign/engine/`: مسیریابی، حرکت، ورودی‌ها و صدا.
- `src/campaign/visual/`: مدل‌سازی اتاق و ربات، جنس سطوح، نور و نمایش وضعیت.
- `src/campaign/ui/`: رابط فارسی، ابزارها و پنجره‌های کوتاه.
- `src/campaign/WorkshopGame.js`: هماهنگ‌کردن حلقهٔ بازی، توقف، ذخیره و چرخهٔ عمر.
- `src/campaign/mount.js`: بارگیری فقط هنگام ورود به حالت داستانی.
- `vendor/three/`: نسخهٔ محلی Three.js و مجوز MIT؛ مصرف‌کنندهٔ سایت برای آن به CDN وصل نمی‌شود.

مدل و نمایش از یک وضعیت مشترک استفاده می‌کنند؛ روشنایی چراغ، نمایش اندازه‌گیری و شرط برد مستقل از هم حدس زده نمی‌شوند. مدل‌های هنری و بافت‌ها در کد تولید می‌شوند؛ از تصاویر Machinarium به‌عنوان دارایی داخل بازی استفاده نشده است.

## اجرا و بررسی
`npm start` سرور Node را روی `http://localhost:8080` اجرا می‌کند؛ build لازم نیست. اجرای قبلی `python -m http.server 5173` و فایل `run.bat` هم معتبر است. بازکردن مستقیم HTML با `file://` کافی نیست.

`npm test` رگرسیون‌های قبلی و آزمون مدل تعمیرگاه را اجرا می‌کند.

برای آزمون مرورگر، ابتدا `npm install` و سپس در دو ترمینال:
1. `npm start -- --port 4173`
2. `npm run test:browser`

آزمون مرورگر با Chrome نصب‌شده اجرا می‌شود. با متغیر `PW_CHANNEL=msedge` می‌توان Edge را انتخاب کرد؛ `STORY_TEST_URL` نشانی پیش‌فرض تست را عوض می‌کند. تصاویر اجرای آزمون در `.test-artifacts/` قرار می‌گیرند و وارد مخزن یا انتشار نمی‌شوند.

معیارهای بررسی: دو مسیر کامل حل در مرورگر، شروع با باتری خالی، بازیابی ذخیره، توقف زمان در پنجرهٔ مدار، ولت‌متر بدون تغییر اتصال، ورودی کیبورد و اجسام سه‌بعدی، جوی‌استیک لمسی و عرض ۳۹۰ پیکسل. آزمون با اندازهٔ موبایل جای سنجش عملکرد روی گوشی واقعی را نمی‌گیرد.

## مرز فعلی اجرا
نمای سه‌بعدی به WebGL2 نیاز دارد؛ در صورت در دسترس نبودن آن، پیام بازیابی نشان داده می‌شود. ذخیره‌ها محلی و مخصوص همین مرورگرند. مراحل بعد، صداگذاری شخصیت‌ها و دارایی‌های هنری دست‌کشیدهٔ نهایی هنوز تولید نشده‌اند.

فایل `.assetsignore` فایل‌های توسعه را از دارایی‌های Cloudflare کنار می‌گذارد؛ فایل‌های `src/` و `vendor/` بخشی از سایت هستند. بازتولید کتابخانهٔ محلی پس از تغییر وابستگی با `npm run vendor` انجام می‌شود. پیاده‌سازی این مرحله به‌تنهایی انتشار روی دامنه انجام نمی‌دهد.
